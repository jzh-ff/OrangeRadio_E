# OrangeSea · 橘子海

Windows 沉浸式音乐播放器——日落渐变暗色视觉，粒子舞台、3D 歌词与桌面模式的私人音乐空间。

本项目是基于 [Mineradio](https://github.com/XxHuberrr/Mineradio)（GPL-3.0）的二次创作，
遵循 GPL-3.0 开源。原作者 XxHuberrr，详见 NOTICE.md。

## 开发

```bash
npm install
npm start
npm run build:win
```
