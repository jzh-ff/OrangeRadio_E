# 胶片电台（Vinyl Radio）播放器样式 实施计划

## 目标

在 OrangeSea 现有底部播放条基础上，新增一个**切换式**播放器皮肤「胶片电台」：全屏沉浸式布局，左侧方形封面+圆形黑胶 CD 探出旋转，右侧歌名/歌手+多行歌词+进度条+控制按钮，底部贯穿 24 根暖金频谱波形条。复古温暖治愈氛围，与「日落渐变暗色」基调协调。通过 `body.film-radio` class 切换，localStorage 持久化用户选择。

## 架构决策（基于探索结论）

1. **样式切换**：完全照抄 `diy-mode` 范式 —— `body.film-radio` class + localStorage `orangesea-film-radio-v1` + `html.film-radio-preload` 防 FOUC
2. **CSS 组织**：新建独立文件 `public/css/film-radio.css`（`body.film-radio` 前缀命名空间），不动 418KB 的 index.css
3. **控制函数全复用**：`togglePlay/nextTrack/prevTrack/toggleLikeCurrent/cyclePlayMode` 等全局函数直接调，零改动
4. **状态读取全复用**：`currentCoverSong()`、`updateControlTrackInfo()`、`setControlCoverSrc()`、`updatePlaybackProgressUi()` 复用
5. **DOM 结构**：保留现有 `#bottom-bar`（id 不变，避免破坏 progress/cover/title 的 getElementById 引用），在 `#desktop-window-shell` 内新增一个平行的 `#film-radio-overlay` 全屏覆盖层；`body.film-radio` 时隐藏原 `#bottom-bar`、显示新覆盖层
6. **歌词**：新写 DOM 多行歌词渲染（复用 `lyricsLines` 数据 + `findStageLyricIndexAtTime()` + `getAdjustedLyricPlaybackTime()`）
7. **频谱**：新写 24 根波形条 DOM，在主循环读全局 `frequencyData` 驱动
8. **CD 封面**：方案 A —— 方形封面（`#control-cover` 的 background-image 同步）+ 圆形黑胶从右侧探出，播放时旋转、暂停停转（`animation-play-state`）

### 2. 切换逻辑（10-shell/06-film-radio.js，照抄 applyDiyMode）

```js
var FILM_RADIO_STORE_KEY = 'orangesea-film-radio-v1';
var filmRadioMode = readBooleanPreference(FILM_RADIO_STORE_KEY, false);

function applyFilmRadioMode(on, opts) {
  opts = opts || {};
  filmRadioMode = !!on;
  document.documentElement.classList.toggle('film-radio-preload', filmRadioMode);
  document.body.classList.toggle('film-radio', filmRadioMode);
  syncFilmRadioButton();
  if (opts.save) saveBooleanPreference(FILM_RADIO_STORE_KEY, filmRadioMode);
  // 进入时同步当前歌曲状态到胶片电台 DOM
  if (filmRadioMode) syncFilmRadioState();
  if (opts.toast) showToast(filmRadioMode ? '胶片电台已开启' : '已切回标准模式');
}
function toggleFilmRadioMode() {
  applyFilmRadioMode(!filmRadioMode, { save: true, toast: true, animate: true });
}
```

### 3. 状态同步（复用现有函数，零侵入）

`syncFilmRadioState()` 在切歌/切模式时调用：
- 封面：监听 `setControlCoverSrc` —— 给原函数包一层，同步设置 `#fr-cover` 和 `#fr-vinyl-label` 的 backgroundImage
- 标题/歌手：监听 `updateControlTrackInfo` —— 同步填充 `#fr-title`/`#fr-artist`
- 进度：监听 `updatePlaybackProgressUi` —— 同步 `#fr-progress-fill` 宽度 + `#fr-time` 文本
- 播放状态：监听 `setPlayIcon` —— 同步 `#fr-play` 图标 + CD 的 `animation-play-state`

**实现方式**：用 MutationObserver 监听 `#control-cover`/`#control-title-text`/`#control-artist`/`#progress-fill`/`#play-icon` 的变化，同步到胶片电台对应元素（不修改原函数，零侵入）。

### 5. 多行歌词渲染（新写，约 80 行 JS）

```js
function renderFilmRadioLyrics() {
  var container = document.getElementById('fr-lyrics');
  container.innerHTML = lyricsLines.map(function(line, i) {
    return '<div class="fr-lyric-row" data-idx="' + i + '">' + escHtml(line.text) + '</div>';
  }).join('');
}
function tickFilmRadioLyrics() {
  if (!filmRadioMode) return;
  var idx = findStageLyricIndexAtTime(getAdjustedLyricPlaybackTime(audio.currentTime));
  if (idx === lastFrLyricIdx) return;
  lastFrLyricIdx = idx;
  // 高亮当前行 + 滚动到视口
  container.querySelectorAll('.fr-lyric-row').forEach(function(row, i) {
    row.classList.toggle('active', i === idx);
  });
  // 滚动：当前行居中
  var active = container.querySelector('.fr-lyric-row.active');
  if (active) container.scrollTop = active.offsetTop - container.clientHeight/2 + active.clientHeight/2;
}
```
监听 `lyricsLines` 变化时重渲染；主循环或 200ms 节流调 `tickFilmRadioLyrics`。

### 6. 频谱波形条（新写，约 40 行）

```js
function buildFilmRadioSpectrum() {
  var container = document.getElementById('fr-spectrum');
  container.innerHTML = '';
  for (var i = 0; i < 24; i++) {
    var bar = document.createElement('div');
    bar.className = 'fr-spectrum-bar';
    container.appendChild(bar);
  }
}
function tickFilmRadioSpectrum() {
  if (!filmRadioMode) return;
  var bars = document.querySelectorAll('.fr-spectrum-bar');
  for (var i = 0; i < 24; i++) {
    // 从 frequencyData 取低中高频段，映射到 24 根条
    var bin = Math.floor(i * 12 + 4);  // 取前 288 个 bin（约 0-6kHz）
    var v = frequencyData[bin] / 255;
    bars[i].style.transform = 'scaleY(' + (0.15 + v * 0.85) + ')';
  }
}
```
在主循环或独立 rAF 调用，读全局 `frequencyData`。

## 风险与对策

- **风险**：MutationObserver 监听可能漏掉某些状态更新。**对策**：同时给关键函数（setControlCoverSrc/setPlayIcon）做轻量包装，双保险
- **风险**：歌词数据 `lyricsLines` 在无歌词时是 fallback 占位。**对策**：检测 `line.fallback` 显示"暂无歌词"
- **风险**：频谱条高频段（高频 bin）数据稀疏。**对策**：用对数映射而非线性，低频段更密集
- **风险**：小窗口下全屏布局拥挤。**对策**：`@media` 断点下简化（隐藏歌词/缩 CD）
